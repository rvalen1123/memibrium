# docs/eval — index of evaluation records

Last confirmed against: aaa5660 (2026-11-02)

Everything in this directory is a dated record of the LOCOMO and LongMemEval evaluation programme: preregistrations (written before a run, fixing the decision rules), results (what a run or an artifact-only audit found), and handoffs (state captured for the next session). Records are not edited after the fact; a correction is a new dated file. The repository-level policy for these files is in `AGENTS.md` (Never: edit the contents of `docs/eval/**` records). `locked_plan.md` is also read by `test_locomo_query_expansion.py`.

Non-markdown siblings (`*.json`, `*.jsonl`, `baseline_run.log`, run directories) are the raw artifacts the markdown files describe; several of those paths are listed in `.gitignore` so that new raw runs are not committed by accident, while the curated ones already tracked stay tracked.

Status values: `preregistration` · `result` · `handoff` · `historical` (kept for the record; its numbers or paths are known to be out of date) · `archived` (moved to `docs/eval/archive/`; none at this pass).

Groups are ordered newest first by the date in the filename; undated files sit at the end of their group. Paths are relative to `docs/eval/`.
